## Source-first finding
Garage Hub v0.7.1 has `forceGlobalImGuiScale` enabled by default and its `applyGlobalImGuiScale()` writes Dear ImGui global state including `io.FontGlobalScale` plus global `FramePadding`, `ItemSpacing`, `WindowPadding`, scrollbar/grab sizing and related style values. That explains why Garage Hub sizing can fight F11/World Editor and why Tow can inherit an unexpectedly huge effective font even while using `SetWindowFontScale` locally.

JOB-09 v0.5.0.30 itself does not globally mutate ImGui scale. It locally pushes style values and calls `SetWindowFontScale`, but that per-window font scale is multiplied by the global font scale, so a globally enlarged scale can still enlarge Tow.

## v0.5.0.31 behavior
- Separates Garage Hub color following from Garage Hub sizing following.
- Existing saves migrate with **Follow Garage Hub Sizing = OFF**.
- Adds **Lock Tow Font Against Global / F11 Scale = ON** by default.
- When locked, Tow reads the current global ImGui font scale and applies the inverse compensation to its own window scale. Tow does not change the global value.
- Adds direct live fine controls for:
  - Font Scale
  - Button / Box Height
  - Master Padding
  - Inside Box Padding
  - Space Between Items
  - Window Edge Padding
- Adds a one-click **RESET TOW UI SIZING TO NORMAL**.
- Presets remain available, but selecting a preset disables Hub sizing follow.
- Garage Hub colors can still be followed independently.
- Existing v0.5.0.30 RLS Tow business Garage + Finances code is unchanged.
- No Tow Yard, Recovery, storage lifecycle, dispatch, payout, abandoned-vehicle, or RLS source behavior is changed.
