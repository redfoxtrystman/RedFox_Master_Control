## RLS vehicle XP tiers confirmed from filters

Repo and Off-Road Recovery use the same major vehicle-value progression tiers:

- low value: 120 base XP
- $25k–$50k budget: 250
- $40k–$100k standard: 500
- $100k–$200k high end: 900
- $200k+ exotic: 1400
- heavy (`us_semi`, `citybus`, `md_series`, `midtruck`): 1800
- Off-Road Recovery trailer: 600

Higher tiers are skill-gated in RLS. JOB-09 v0.5.0.25 mirrors that by capping target base XP to the highest native tier available at the player's current Recovery level rather than allowing a high-value RedFox call to bypass native progression pacing.

## JOB-09 v0.5.0.25 implementation

All completed RedFox towing/recovery work now feeds `careerSkills-recovery`.

### Standard RedFox work — Repo-style XP

- Standard Car Tow
- Abandoned Vehicle Recovery
- ordinary tow/impound work

Uses the RLS Repo-style `1x` Recovery XP structure.

### Recovery/scene work — Off-Road-style XP

- Roadside Rolled-Vehicle Recovery
- Semi / Trailer Rollover Recovery
- Roadway Accident Scene Cleanup / multi-car crash

Uses the RLS Off-Road-style `2x` structure.

For multi-target RedFox scenes, each recovered target contributes its RLS-tier base XP. Route-distance XP reflects the expected repeated tow distance for the target count.

### Completion rather than sale

Recovery XP is earned for doing the actual recovery, not for monetizing the recovered asset later.

Therefore v0.5.0.25 awards Recovery XP when:

- a normal paid RedFox job completes;
- an unpaid impound/recovery completes;
- refused delivery is returned to Tow Yard custody;
- an abandoned vehicle is stored in the yard;
- an abandoned vehicle is immediately disposed after the recovery;
- a non-lienable recovered item is safely closed;
- the paid-mission Force Complete failsafe is used.

It does NOT add Recovery XP to:

- later salvage sales;
- valuables searches;
- direct Tow Yard vehicle sales;
- business vehicle sales;
- refunds;
- future FoxNet auction proceeds.

This prevents selling the same recovered asset later from granting towing XP twice.

## Duplicate protection

JOB-09 v0.5.0.25 adds a persistent `recoveryRewardLedger` keyed by the RedFox event ID plus checks pending rewards before queueing another Recovery reward. The ledger is capped to the newest 750 entries.

This prevents normal repeated completion/reload paths from creating duplicate Recovery XP for the same Tow event.

Native Repo and Native Off-Road Recovery never enter this RedFox event reward ledger; RLS remains authoritative for those activities.

## Difficulty scaling

JOB-09 adds `careerSkills-recovery` to the same reward table passed through RLS's `career_modules_difficultyMode.scalePaymentRewardData(..., {includeMoney=false})`, matching RLS Repo/Off-Road behavior. JOB-09's quoted Tow cash itself remains unchanged by this integration.
