## Runtime evidence

David successfully moved a lien/custody record into the virtual **Tow Company Garage**, proving the first half of the new flow works.

The selected company record then displayed:

- `Vehicle stage: TOW COMPANY GARAGE`
- assigned exact tow yard;
- `Deliver to Linked RLS Garage` action;
- warning: `Link this exact RedFox tow yard to a purchased RLS garage first.`

A separate existing company-fleet record remained blocked by:

`SAFETY LOCK — LEGACY COMPANY GARAGE MOVEMENT IS DISABLED`

The legacy record reports `virtual_company_garage` and `Removed from personal inventory: Yes`, but v0.4.4.5 exposes no safe migration/delivery action.

## Confirmed defects

1. The custody-to-company transaction works, but the physical delivery flow is not self-contained. The player must leave the selected vehicle page, find Tow Yard Manager, discover a purchased-garage candidate, link it, return to the company record, and retry delivery.
2. When no exact-yard link exists, the selected record page does not provide a direct garage chooser/link action.
3. Existing legacy company records remain permanently read-only even when they contain enough identity data to be safely reconciled with native Career inventory.
4. The system does not distinguish three legacy states clearly:
   - native inventory ID still exists;
   - native inventory ID was removed and can be recreated once;
   - identity/provenance is insufficient and must remain locked for manual review.
5. The selected screenshot record appears to be equipment (`FP Crane Chains 2 rotatable chains`) rather than a normal road vehicle. Non-vehicle equipment must not be delivered into native Career garage inventory as if it were a titled vehicle unless exact configuration validation proves it is a complete loadable vehicle.

## Authorized v0.4.4.6 repair scope

- Add a garage-link chooser directly beside the selected Tow Company Garage record.
- Auto-link only when exactly one valid purchased garage exists on the current map and the player explicitly confirms delivery.
- Show all valid purchased garages, capacity state, existing link ownership and precise block reason.
- Preserve one-to-one exact-yard-to-garage ownership.
- Add safe legacy-record reconciliation:
  - adopt the existing native inventory ID when it still exists;
  - otherwise create one native inventory vehicle exactly once only when model/config identity is complete and no prior delivery transaction exists;
  - preserve pending inventory ID and transaction ID through reload;
  - remove the virtual legacy record only after exact garage placement verifies;
  - lock ambiguous/conflicting records with a clear manual-review reason.
- Prevent non-vehicle equipment/attachments from entering native garage delivery; route them to company equipment storage, sale, scrap or found-property handling instead.
- Keep v0.4.4.5 as rollback.
- Do not modify Browser Core, JOB-04, JOB-13, Random Events or stock Career/RLS files.

## Required transaction protections

- no duplicate native inventory vehicle;
