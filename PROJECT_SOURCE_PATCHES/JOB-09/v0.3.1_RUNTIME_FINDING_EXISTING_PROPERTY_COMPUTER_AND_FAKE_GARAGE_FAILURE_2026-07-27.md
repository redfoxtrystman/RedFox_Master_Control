David completed enough runtime testing to prove that the v0.3.1 separate RedFox garage design is wrong for an existing purchased property.

## What happened

A RedFox tow yard was created as a separate location named `Tow Yard 1` instead of designating the existing RLS garage at the purchased service-station property.

The company vehicle was moved to that artificial Tow Yard 1 location. The normal RLS property computer still belonged to the existing RLS garage ID:

`servicestationGarage`

Because the vehicle location and the computer garage ID did not match, the normal RLS My Vehicles menu treated the vehicle as being at another garage and offered the stock Deliver action.

Observed stock behavior:

- $5,000 delivery charge
- approximately 120-second delivery delay
- Deliver and Deliver and replace options instead of immediate Retrieve

This is consistent with the normal RLS delivery path, but it is not acceptable for a vehicle already assigned to the same physical tow property.

## Additional runtime finding

The generated RedFox Fleet Computer was not the correct access point for this property. The property already has an RLS computer/facility. JOB-09 should add tow-yard functions to that existing computer instead of creating a separate runtime computer and separate garage.

## Owner decision

When a purchased property is designated as a tow yard:

> The property's existing RLS garage is the tow yard.

JOB-09 must not create a second RLS garage beside or inside that property.

Correct relationship:

```text
RedFox tow-yard business record
  -> existing purchased property
  -> existing RLS garage ID
  -> existing RLS computer facility
```

Example:

```text
RedFox yard ID: redfox_tow_yard_001
Custom yard name: RedFox Main Yard
RLS garage ID: servicestationGarage
Map: west_coast_usa
```

The RedFox yard ID preserves business identity, records, custody inventory, and the user's custom display name. The existing RLS garage ID controls normal owned-vehicle storage, My Vehicles grouping, retrieval, parking locations, and physical spawning.

## Required correction for the next patch

1. Stop registering separate `redfox_towshop_*` RLS garage locations for properties that already have an RLS garage.
2. Add a tow-yard designation record that points to the existing RLS garage ID.
3. Detect the existing computer facility linked to that garage ID.
4. Add RedFox Tow Yard Management functions to the existing computer without replacing its stock RLS functions.
5. Support a custom RedFox tow-yard display name while keeping the stable RLS garage ID unchanged.
6. Migrate vehicles from the artificial Tow Yard 1 location back to the property's real RLS garage ID.
7. Preserve the same RLS inventory ID, `owned=true`, configuration, paint, condition, mileage, insurance data, and thumbnail.
8. Remove the $5,000 fee and 120-second delay from RedFox same-property transfers.
9. Confirm the stock RLS computer shows Retrieve or Replace for a vehicle assigned to its own garage.
10. Remove or disable the artificial RedFox Fleet Computer created by v0.3.1 after safe migration.
