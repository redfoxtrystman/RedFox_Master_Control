## Implemented changes

### Same-yard lien claim

- Claim no longer requires a purchased personal Career/RLS garage.
- Exact custody record is staged into the same `levelId::yardId` company/shop storage.
- Claim charge is linked to a persistent transaction ID.
- The custody record is restored if staging or payment fails.
- A crash after payment but before final marking is reconciled from the exact business-ledger transaction ID.
- Condition, damage, part-condition, paint, mileage, value and source fields are preserved when present.
- Company capacity includes assigned company fleet, new virtual shop assets and protected legacy company-garage records.

### Legacy claim safety

- Old `claimPending` records are reconciled on load.
- If no owned inventory record exists, stale pending flags are cleared.
- If an old claim already created a Career inventory ID, the custody record remains blocked for manual review.
- JOB-09 does not automatically delete or duplicate that Career vehicle.

### Optional personal storage transfer

- `Send to Personal/RLS Garage` is separate from claim.
- It requires a valid purchased-garage link and native space.
- The virtual company/shop record is removed only after one Career inventory ID and its exact garage placement verify.
- Failure removes the newly created inventory object and leaves the virtual company asset intact.

### Random Events payment routing

- Normal paid tow remains the default.
- Random payer default remains a minority outcome.
- Defaulted lienable vehicles enter exact-yard custody and start the existing lien process.
- Defaulted non-lienable equipment/attachments/found property close without a title or vehicle lien.
- Mixed lienable/non-lienable imported scenes record both outcomes.

### Random Events placement

- JOB-09 applies a temporary per-event road/spawn context when the installed scanner supports it.
- Existing scanner context is captured and restored where the API exposes it.
- Tunnel/enclosed locations are rejected by default.
- Road-link and full-scene validation use limited retries rather than unlimited spawn loops.
- Tunnel scenes remain available only through an explicit development setting.
- No Random Events file is copied, patched or overridden.

### Rail/Train classification

- Short/common category tokens now use Lua frontier-boundary matching.
- `train` no longer matches `drivetrain` or `streettrain`.
- Exact train forms such as `train`, `train-config` and `train_config` remain classifiable.

### Runtime package cleanup

The final test artifact will be built from an explicit 16-file runtime allowlist. Reports, diffs, historical audits, development backups, external catalog-manager files, screenshot instructions and source notes will stay outside the BeamNG mod ZIP.
