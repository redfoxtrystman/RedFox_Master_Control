# JOB-09 v0.2.8 Source Change Summary

## Changed runtime file

`lua/ge/extensions/redfoxTowRecoveryDispatch.lua`

## Added

- Runtime-only Temporary Vehicle Spawn Lab state.
- Metadata-token groups for aircraft, boats, motorcycles/three-wheelers, construction equipment, and rail vehicles.
- Cached category pools built from `util.configListGenerator.getEligibleVehicles(false, false)`.
- Category test buttons in the WE UI below the existing call chooser.
- Safe nearby test spawning using the player vehicle transform.
- Larger initial distance for aircraft, rail, boats, heavy trucks, semis, trailers, buses, tow equipment, and construction equipment.
- `Remove Last` and `Remove All` temporary-spawn cleanup.
- Extension-unload cleanup.
- Per-action `[RedFox][TOW][DEV_SPAWN]` diagnostics.

## Isolation rules

- Spawn Lab blocks while an offer or active call exists.
- Lab spawns skip tow-target/traffic preparation.
- Lab spawns are not added to calls, tow-yard storage, Fleet Book, payments, or Career inventory.
- Existing five manual call buttons and dispatch logic remain unchanged.

## Save compatibility

No save schema or file path changed. v0.2.7 Fleet Book, yard, history, settings, and impound data remain compatible.

## Explicitly not implemented

- Proximity-completed lockout, tire, battery, or fuel calls.
- In-game camera fleet photographs.
- Company/tow-garage inventory transfer.
- RLS personal-vs-company garage integration.
